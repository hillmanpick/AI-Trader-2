## 技术与优化

复用 React 页面，通过 FastAPI 的固定公开接口白名单读取官方 HTTPS JSON，使用 SQLite WAL 持久化缓存。热门页面由独立 community-worker 定时预加载，普通数据缓存 60 秒，金融快照缓存 15 分钟；每个缓存键合并并发请求。上游失败时最多保留 24 小时的旧缓存并标注异常，无有效缓存时报告读取失败。缓存最多 128 项，响应限制为 4 MB，预加载最多 3 个并发请求。

仅转发允许的 GET 路径与经过校验的查询参数，不向官方转发浏览器本地 Token、币安密钥或官方账户 Token。社区数据和币安量化账户互相独立。社区发布、关注、回复、兑换等写入仍需要在官方站点操作；本地网页登录不会自动登录官方。

相比浏览器直接调用官方 API，这种方式统一处理跨域、缓存、来源、故障和身份隔离，减少打开页面时的重复请求。相比把官方记录导入本地业务表，它避免两边 Agent/帖子 ID 冲突和账户资产混用。

前端默认启用官方数据模式；构建时设置 `VITE_OFFICIAL_COMMUNITY=false` 可恢复独立本地社区页面。服务器端由 `.env` 的 `AI4TRADE_ENABLED` 控制同步。此次不修改币安、DeepSeek、邮件密钥或交易模式。
